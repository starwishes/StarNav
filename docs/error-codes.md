# 错误码参考文档

## 标准响应格式

```json
{
  "success": false,
  "error": "错误描述",
  "code": "ERROR_CODE",
  "details": "..." // 开发环境下显示
}
```

## HTTP 状态码

| 状态码 | 说明       | 常见场景                          |
| ------ | ---------- | --------------------------------- |
| 200    | 成功       | 请求成功处理                      |
| 201    | 已创建     | 资源创建成功                      |
| 400    | 请求错误   | 参数缺失、格式非法                |
| 401    | 未认证     | 未登录或 Token 过期               |
| 403    | 禁止访问   | 权限不足 (如普通用户访问管理接口) |
| 404    | 未找到     | 资源不存在                        |
| 409    | 冲突       | 资源已存在 (如重复的 URL/用户名)  |
| 429    | 请求过多   | 触发限流保护                      |
| 500    | 服务器错误 | 系统内部异常                      |

## 业务错误码

| 代码                 | 说明       | 解决方案                           |
| -------------------- | ---------- | ---------------------------------- |
| `AUTH_REQUIRED`      | 需要登录   | 请跳转至登录页面                   |
| `INVALID_TOKEN`      | Token 无效 | Token 签名错误或已失效，请重新登录 |
| `PERMISSION_DENIED`  | 权限拒绝   | 当前用户等级不足                   |
| `RESOURCE_NOT_FOUND` | 资源未找到 | 检查 ID 是否正确                   |
| `DUPLICATE_ENTRY`    | 数据重复   | 检查是否重复提交 (如 URL 已存在)   |
| `VALIDATION_ERROR`   | 验证失败   | 检查输入字段格式                   |
| `DB_ERROR`           | 数据库错误 | 联系管理员检查数据库状态           |
| `SYSTEM_INIT_ERROR`  | 初始化失败 | 检查系统配置或环境变量             |

## 验证错误示例

当 `code` 为 `VALIDATION_ERROR` 时，错误信息通常包含具体字段：

- "无效的 URL 格式"
- "分类名称不能为空"
- "密码长度不能少于 6 位"
